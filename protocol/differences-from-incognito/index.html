Differences from Incognito

What Zephyrium changed, what it kept, and the naming table.

Zephyrium started from Incognito Chain (see NOTICE for the exact source). This page lists what has changed and what has deliberately stayed the same.

Changed​

AreaIncognitoZephyrium
CoinPRV, 100M capZEP, 1,000,000,000 cap
Minting9% yearly decrease, no end date10% yearly decrease, ends after 21 years
Reward split10% to the DAO falling to 3%, rest to validators309/330/330/10 of 979 to validators, finance, DAO, satoshi
Minting capEnforced only from a later block versionCounted from the first block
Shard stake1,750 PRV, hard-coded21,000 ZEP, set in config
Beacon stake minimum87,500 PRV, hard-coded210,000 ZEP, set in config
Local network genesisCoins on a publicly known test key21,000,000 ZEP on a freshly generated key
Local network committee keysDerived from a public passphraseGenerated from fresh randomness
HighwaySeparate repositoryBundled under ./highway
Highway bugStaked validators could not report features and were never seatedFixed
Devnet scriptsKeys written into scriptsKeys read from an uncommitted secrets file

Not changed​

The privacy transaction system, the consensus protocol, the DEX and the bridge code are as inherited. Zephyrium has not yet changed any cryptography.

Known inherited limits that are planned work, not finished work, are in the roadmap.

Names​

IncognitoZephyriumRenamed in code?
IncognitoZephyriumYes, in text and the Go module path
PRVZEPThe display name is ZEP. Identifiers and JSON fields such as FeeInPRV, and the "PRV" key in RPC replies, are unchanged.
Incognito WalletiWalletSeparate project, not in this repository
incognito (the program)incognitoNo
INCOGNITO_* environment variablesunchangedNo
pDEXiDEXNo; the code and RPC methods still say pdex
pTokeniTokenNo

Identifiers, RPC field names and the program name are left as they are on purpose. Renaming them would break wallets and tools that talk to a node, and would change stored chain data.

In documents, "Incognito" is kept wherever it refers to the upstream project or its history.
